# 斷電恢復改版：板子上的驗證步驟

## 0. 燒新版之前：先用舊版跑一次 A

這樣才有「改之前」的證據。舊版在第二次重開後會變成：

```
[LOG ] init: 3 valid, 1 corrupt, wp=0x002000, next_id=4 oldest=S0 active=S1 (recovered)
...
  [4] @0x002000 len=4 ... crc=BAD
```

write pointer 又跳回 0x002000，`good` 被 `next` 疊寫，兩筆都壞了。

## 1. 燒錄新版，先 `log format`

新版的 header 多了 CRC-16，舊格式的 record 會被當成壞掉，所以要先清空。

`(reset)` 的意思是按板子上的黑色 reset 鍵，`log remount` 也可以。

## A. 寫到一半 → 重開 → 寫一筆 → 再重開

```
log format
log write hello
log write world
log partial abcdefghij
(reset)
log write good
(reset)
log write next
log dump
```

預期：

- 第一次重開：`init: 2 valid, 1 corrupt, wp=0x002000 (full), next_id=4 oldest=S0 active=S0 (recovered)`
- 第二次重開：`init: 3 valid, 1 corrupt, wp=0x002018, next_id=5 oldest=S0 active=S1`
- dump：`[4] @0x002000 ... crc=OK "good"`、`[5] @0x002018 ... crc=OK "next"`

## B. 換 sector 時，PAD 寫完就斷電

```
log format
log fill 48 64
log padcut
(reset)
log write short
(reset)
log dump 47 5
```

預期：

- 重開：`init: 48 valid, 0 corrupt, wp=0x002000 (full), next_id=49 ... (recovered)`
- 再重開：`init: 49 valid, 0 corrupt, wp=0x002019, next_id=50 oldest=S0 active=S1`
- dump：`[49] @0x002000 len=5 ... crc=OK "short"`（舊版會把它疊寫在 0x001FC0 的 PAD 上）

## C. 下一個 sector 不是全 FF（模擬擦到一半）

```
log format
log fill 70 32
write 0x002000 garbage
log fill 20 32
log stats
log dump 76 5
```

預期：

- stats：`records=90 corrupt=0`，`erases=1`（跨進 S1 前發現不是全 FF，先擦了）
- dump：`[79] @0x002000 ... crc=OK`

## D. 剛好填滿 sector，並繞過一圈

```
log format
log fill 1100 44
log stats
(reset)
log stats
```

預期（44 B payload ＝ 64 B 一筆，每個 sector 剛好 64 筆）：

- 兩次 stats 都是 `records=972 corrupt=0 sectors=16/16 wp=0x002300 next_id=1101`、`oldest=S2 active=S1 erases=2`
- 舊版在這裡 write pointer 會跑到 0x011000（log 區外面）

## E. header 寫到一半

```
log format
log write hello
log tornhdr
(reset)
log write after
(reset)
log dump
```

預期：

- 重開：`bad header @0x001019, skip rest of sector`，`init: 1 valid, 1 corrupt, wp=0x002000 (full), next_id=3 ... (recovered)`（讀不出那筆的編號，直接跳過一號）
- dump：`[1] "hello"`、`[?] @0x001019 bad header`、`[3] @0x002000 "after"`

## 時間欄位

`t=`、`last_append_us` 這些數字每次都不一樣，不用比對。
